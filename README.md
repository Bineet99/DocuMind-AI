# DocuMind AI – Intelligent PDF & Notes Assistant

**Project Overview**

Developed DocuMind AI, an AI-powered document intelligence application that uses Retrieval-Augmented Generation (RAG) to make PDF document analysis and information retrieval faster and more efficient.

**Key Features**
- **PDF Upload & Processing:** Upload PDF documents and extract their textual content for analysis.
- **Intelligent Question Answering:** Ask natural-language questions and receive context-aware answers based on uploaded documents.
- **Semantic Search:** Uses Sentence Transformers and FAISS to retrieve relevant document sections.
- **Source References:** Provides relevant page references to help users verify generated answers.
- **AI-Powered Summarization:** Generates short summaries, detailed summaries, and key-point summaries.
- **Conversational Interface:** Supports chat history for more contextual interactions.

**Technologies Used**

Python, Streamlit, FastAPI, FAISS, Sentence Transformers, OpenRouter API, PyTorch.

**Outcome**

Successfully developed an end-to-end RAG-based PDF assistant that combines semantic search with LLM-powered response generation. The application simplifies document understanding by allowing users to interact with PDFs through natural-language queries, access relevant information with source references, and generate automated summaries.
